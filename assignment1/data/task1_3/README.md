# Task 1.3 data placeholder

Place the original CSV files and images for the six supplied course visualizations here. The task1_3 script expects to find CSVs and/or images in this directory when you're ready to run the fixes.

Recommended naming convention (examples):
- orig_viz_1.csv
- orig_viz_1.png
- orig_viz_2.csv
- orig_viz_2.png

When you add files here, run:
  python task1_3/task1_3.py

which will list available files and act as a starting point for the reconstruction scripts.
