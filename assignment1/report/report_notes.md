Report notes and suggested structure for Assignment 1

Suggested outline for the final report:

1. Introduction
   - Briefly restate the assignment goals.

2. Task 1.1 — Intentionally bad visualizations
   - Show each of the three bad visualizations with captions.
   - Under each figure, include a short explanation relating the problem to expressiveness, effectiveness, or appropriateness.

3. Task 1.2 — Parallel Coordinates and Dimensional Stacking
   - (a) Variable type identification
   - (b) Parallel coordinates plot (include figure)
   - (c) Dimensional stacking (include figure)
   - (d) Brief discussion comparing the two methods and recommending one for this dataset.

4. Task 1.3 — Fix two visualizations
   - For each selected visualization:
     - Show the original image.
     - List identified problems and classify them (expressiveness/effectiveness/appropriateness).
     - Show the improved image and explain the changes.
     - Discuss why the improved version is better.

5. Conclusion

File naming and figure placement
- Keep all generated images in the task-specific figures/ directories to make them easy to find and include in the report.
