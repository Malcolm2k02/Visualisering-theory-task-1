Notes and instructions for Task 1.1

Task 1.1 requires three intentionally bad visualizations. For each visualization you should:

- Create the plot in task1_1/task1_1.py (or import helper modules if you prefer).
- Save the figure inside task1_1/figures/ using the naming convention:
  - non_expressive.png
  - inefficient.png
  - inappropriate.png
- Add a short written explanation (2-6 sentences) explaining why the visualization is bad. Relate the explanation to
  visualization principles (expressiveness, effectiveness, appropriateness). Add these explanations below each figure in this notes.md file or in a separate markdown file.

Hints:
- Non-expressive: A plot that cannot represent the data values accurately (e.g., missing axis labels, wrong chart type for the data).
- Inefficient: A plot that wastes perceptual resources or requires unnecessary effort to decode (e.g., encoding a single value with many visual elements, overplotting without aggregation).
- Inappropriate: A plot that misleads or is an unsuitable mapping for the task (e.g., using 3D for simple 2D comparisons, truncated axes that exaggerate differences).

Remember: Do not copy examples directly from lecture slides. Create original, intentionally bad examples instead.
