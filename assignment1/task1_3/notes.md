Notes and instructions for Task 1.3 — Fix two visualizations

This folder contains starter code to support selecting and improving two visualizations from the six provided by the course.

What to place in data/task1_3/
- Original CSV files and images for each of the six course visualizations. Use descriptive filenames, for example:
  - orig_viz_1.csv
  - orig_viz_1.png
  - orig_viz_2.csv
  - orig_viz_2.png

How to proceed
1. Add the original files to assignment1/data/task1_3/.
2. Update task1_3/task1_3.py to load the selected CSVs and implement fix_visualization_1() and fix_visualization_2().
3. Save improved figures to task1_3/figures/ using the naming convention:
   - improved_viz_1.png
   - improved_viz_2.png
4. In your final report, show the original and improved visualizations side-by-side. Use the same scale and sizing for fair comparison.

Notes on analysis
- For each original visualization, explicitly identify problems and explain whether they are: expressiveness, effectiveness, or appropriateness issues.
- Describe what you changed and why the improved version is better.
